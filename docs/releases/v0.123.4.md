Map Rando v123, world revision 4.

## Fixed

- **Patching a seed with the wrong version now says so.** Patching used to fail with just a key name, such as
  `'customize_settings'` (a 0.123.2 or earlier `.apsmmr` patch opened by lordlou's Map Rando world, which used the same
  game name and patch extension) or `'customize'`. Patches made with this version record the version that generated
  them, and patching one with another version stops with a message naming both versions, e.g. "This patch was made by
  Super Metroid Map Rando Upstream 0.123.4, but 0.124.0 is installed. Patch it with 0.123.4 (the version that
  generated the seed), or generate the seed again with 0.124.0."

**Updating:** seeds generated with 0.123.3 patch with 0.123.3 only; generate them again with 0.123.4, or keep 0.123.3
installed to play them. Seeds generated with 0.123.2 or earlier (`.apsmmr` patches) still need that version: see the
[0.123.3 notes](https://github.com/JimLundin/sm-map-rando-archipelago/blob/main/docs/releases/v0.123.3.md).
