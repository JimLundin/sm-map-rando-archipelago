Map Rando v123, world revision 3.

## The world has a new name: Super Metroid Map Rando Upstream

This world used the same names as [lordlou's Map Rando world](https://github.com/MultiworldGG/MultiworldGG/tree/main/worlds/sm_map_rando),
so only one of the two could be installed, and the SNI client could take one world's ROM for the other's. It's now
called **Super Metroid Map Rando Upstream** (it tracks upstream Map Rando), and the two can be installed side by side.

| | Before | Now |
|---|---|---|
| Game | `Super Metroid Map Rando` | `Super Metroid Map Rando Upstream` |
| World file | `sm_map_rando.apworld` | `sm_map_rando_upstream.apworld` |
| Patch files | `.apsmmr` | `.apsmmru` |
| Options template | `Super Metroid Map Rando.yaml` | `Super Metroid Map Rando Upstream.yaml` |

**Updating:**

- Remove `sm_map_rando.apworld` from `custom_worlds` (unless you use it for lordlou's world, which has the same file
  name) and add `sm_map_rando_upstream.apworld`.
- In your YAML, change `game: Super Metroid Map Rando` and the `Super Metroid Map Rando:` options key to
  `Super Metroid Map Rando Upstream`, or start from the new template.
- Seeds generated with 0.123.2 or earlier (`.apsmmr` patches) need that version to patch and play; this version doesn't
  open them.

## Fixed

- **Patching could fail the first time**, with `[Errno 2] No such file or directory: ...Mosaic-....tar` or
  `Loading tilesets.bps: The system cannot find the file specified`. The first patch downloads and unpacks Map Rando's
  room tile patches, which takes a while; opening the patch file again in the meantime started a second client that
  removed the first one's files. Two clients can now set things up at the same time, and an incomplete set of tile
  patches left behind by an earlier version is repaired automatically (no need to clear the cache).
- The same could happen to the Map Rando data and the native randomizer unpacked from the `.apworld` on a fresh
  install.

## Options

- Every cosmetic option now says where maprando.com shows it, e.g. Statues Hallway tiling and Statues Hallway audio
  are the website's "Tourian proximity theming" (`statues_hallway_tiling`, `statues_hallway_audio`).
